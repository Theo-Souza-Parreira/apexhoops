# 📖 Sobre o Projeto

O **ApexHoops** é um projeto de TCC desenvolvido com o objetivo de tornar o treinamento individual de basquete mais acessível através da tecnologia.

A plataforma irá auxiliar jovens atletas no desenvolvimento técnico utilizando:
- treinos organizados por nível
- exercícios específicos por posição
- acompanhamento de evolução
- conteúdos acessíveis para prática individual

O projeto busca unir:
- esporte
- tecnologia
- inclusão
- desenvolvimento pessoal

---

# 🎯 Objetivo

Desenvolver uma plataforma digital voltada ao auxílio de treinamentos individuais de basquete, democratizando o acesso a conteúdos técnicos e incentivando a prática esportiva.
